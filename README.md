# Higher Math Coursework App

A native iOS application for learning Calculus I and Linear Algebra through structured lessons, interactive practice, and revision activities. Developed as a coursework software product.

## Overview

MathGo is designed for first- and second-year university STEM students who want to study higher mathematics through a structured and interactive mobile format. The application offers learning paths for Calculus I and Linear Algebra, guiding users through theoretical explanations, visual demonstrations, practice tasks, and revision activities using a consistent read → visualise → practice → revise progression model.

## Features

- Email-based authentication and persistent sessions via Supabase
- Personalised welcome screen displaying the user's name
- Calculus module covering Derivatives and Integrals
- Linear Algebra module covering Vectors and Matrices
- Gradual content reveal mechanic for focused, step-by-step learning
- Interactive practice tasks with immediate feedback and solution explanations
- Formula matching and theory revision games
- Reusable component system for consistent UI and logic across all modules

## Tech Stack

- Swift
- SwiftUI
- Xcode
- Supabase Authentication
- Supabase PostgreSQL Database

## Project Structure

```
MathGo/
├── Authentication/     # Sign-in, sign-up, session management
├── Main/               # Home screen, topic selection
├── Calculus/           # Derivatives and Integrals learning paths
├── LinearAlgebra/      # Vectors and Matrices learning paths
├── Components/         # Reusable UI and data model structures
└── Supabase/           # Client initialisation and profile management
```

## Status

Developed as a coursework software product. The application runs locally on iOS simulator and physical devices via Xcode.
